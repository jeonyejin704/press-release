# 🌱 베이비봉 대시보드

5주차부터 출산까지, 부부가 함께 보며 준비하는 출산 준비 대시보드예요.

## 여는 방법
- `babybong/index.html` 파일을 브라우저로 열면 됩니다. (더블클릭 또는 브라우저에 드래그)
- 별도 설치·인터넷 연결 없이 동작해요. 뉴스/공식사이트 링크만 클릭 시 인터넷이 필요합니다.

## 담긴 내용
1. **주차·D-day 카운터** — 마지막 생리 시작일을 넣으면 임신 주차·출산 예정일이 자동 계산돼요.
2. **지금 할 일** — 임신 초기(5~12주) 우선순위 체크리스트.
3. **제도·지원** — 정부(전국) / 지자체(포항·경북) / 학교(POSTECH) 탭별 지원 제도.
4. **먹거리 가이드** — 주차별 영양제 타임라인 + 피해야 할/좋은 음식.
5. **정기검진 로드맵** — 주요 산전검사 시기.
6. **예산 계획** — 지원금·지출 금액을 직접 넣으면 순부담이 실시간 계산.
7. **뉴스 모니터링** — 임산부 관련 최신 뉴스 검색 바로가기.
8. **함께하기** — 남편 역할·마음 챙기기.

## 저장
체크 상태, 예산 입력값, 생리 시작일, 테마는 **여는 브라우저에 자동 저장**돼요.
> 참고: 저장은 브라우저 로컬(localStorage) 기준이라, 다른 기기/브라우저에서는 각각 따로 저장됩니다.

## 주의
- 지원금·제도 정보는 **2026년 일반 기준**이에요. 지자체·학교 항목은 신청 전 공식 창구에서 최신 정보를 꼭 확인하세요.
- 의료·영양 내용은 일반 정보입니다. 개인 건강 판단은 담당 산부인과 의료진과 상의하세요.
